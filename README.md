# 🌿 Plantify – Plant Store Landing Page

Plantify is a plant store landing page designed to showcase indoor plants and create a simple, attractive shopping experience.

## ✨ Features

- Clean and modern design
- Navigation bar
- Hero section
- Plant categories section
- Featured products section
- Benefits section
- About section
- Promotional section
- Footer
- Mobile responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## 📱 Responsive Design

The website is designed to work on desktop and mobile screens.

## 🌐 Live Demo

[View Plantify Website](https://mestrydipti94.github.io/plantify-landing-page/)

## 📂 Project Files

- `index.html` – Website structure
- `style.css` – Website styling and responsive design
- `plant1.png` – Plant image asset

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
